# Análise de Frota (Gobrax)

Painel estático (HTML + JS), sem servidor. Os dados (clientes e planilhas) ficam no navegador de cada pessoa (localStorage).

## Publicar no GitHub Pages
1. Crie um repositório (ex.: `analise-frota`) e envie estes arquivos na raiz.
2. Settings → Pages → Source: "Deploy from a branch" → Branch `main` / pasta `/ (root)`.
3. O link sai em `https://<org-ou-usuario>.github.io/analise-frota/`.

## Observações
- O repositório/Pages contém só o código; nenhuma planilha ou dado de cliente vai junto.
- Fora do Claude, não há banco compartilhado: cadastro de clientes e planilhas valem por navegador.
